<h1 align="center">📝 MERN Stack Note Taking App ✨</h1>


##  .env Setup

### Backend (`/backend`)

```
MONGO_URI=<your_mongo_uri>

>

NODE_ENV=development
```

## 🔧 Run the Backend

```
cd backend
npm install
npm run dev
```

## 💻 Run the Frontend

```
cd frontend
npm install
npm run dev
```
